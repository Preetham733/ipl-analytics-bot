# 🏏 IPL Analytics Bot (2008-2025)

An interactive cricket analytics dashboard powered by AI.

## 🔗 Live Demo
[Click here to view the app](https://ipl-analytics-bot-wafu5zbvtnz59uhleccgjk.streamlit.app)

## ✨ Features
- 📊 Team Stats — Season wise wins, top scorers, wicket takers
- 🏏 Player Stats — Full batting & bowling profile with role detection
- ⚔️ Head to Head — Detailed match scorecards & H2H records
- 🤖 AI Bot — Ask anything about IPL powered by Llama 3.3

## 🛠️ Tech Stack
- Python, Streamlit, Pandas, Plotly
- Groq API (Llama 3.3 70B)
- IPL Dataset 2008-2025
